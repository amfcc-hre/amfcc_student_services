Website replacement:
1. Extract amfcc_student_services_platform_v6_full_stack.zip.
2. Open https://github.com/amfcc-hre/amfcc_student_services
3. Open the main branch and select Add file > Upload files.
4. Select every extracted file.
5. Upload the files directly into the repository root.
6. Do not upload the ZIP and do not create another folder.
7. Allow GitHub to replace all matching files.
8. Commit the upload.
9. Wait for GitHub Pages to finish publishing.
10. Press Ctrl + F5 twice on:
    - admin_index.html
    - dashboard_index.html
    - passes_index.html
    - meal_index.html
11. Close and reopen Edge on the gate kiosk if an old version remains.
